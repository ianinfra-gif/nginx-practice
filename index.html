01

Linux（作業系統）基礎

路徑、檔案、資料夾與權限：先熟悉最常用的終端機操作。

11 條
查看目前位置路徑

顯示目前工作目錄的完整路徑。

補充要確認自己正在哪個資料夾時先用它。

pwd
切換目錄路徑

前往指定資料夾，改變後續指令的執行位置。

補充例如：cd /var/log；cd .. 返回上一層；cd ~ 回家目錄。

cd [路徑]
列出詳細檔案資訊檢視

同時顯示隱藏檔、權限、擁有者及檔案資訊。

補充-l 顯示詳細資訊；-a 包含以點號開頭的隱藏檔。

ls -la
讀取檔案內容檢視

將文字檔完整內容顯示在終端機。

補充適合較短的文字檔；過長的檔案可改用 less [檔名] 分頁查看。

cat [檔名]
編輯文字檔編輯

使用 Vim（文字編輯器）開啟或建立檔案。

補充按 i 開始輸入；Esc 離開輸入模式；:wq 儲存離開；:q! 放棄修改離開。

vim [檔名]
建立資料夾檔案

在目前目錄建立新資料夾。

補充建立多層資料夾可使用 mkdir -p [路徑]。

mkdir [名稱]
複製檔案檔案

複製檔案到指定位置。

補充若來源是資料夾，通常需加 -r；留意同名檔案可能被覆蓋。

cp [來源] [目的地]
移動或重新命名檔案

把檔案或資料夾移至其他位置，也能直接改名。

補充目標已有同名檔案時可能被覆蓋；可用 mv -i 先提示確認。

mv [來源] [目的地]
刪除檔案謹慎

從檔案系統刪除指定檔案。

注意注意：通常不會進入資源回收筒。避免不明確的 rm -rf 操作。

rm [檔名]
修改檔案權限權限

調整檔案或目錄的讀取、寫入、執行權限。

補充例如 chmod +x script.sh 讓腳本可執行；修改前先用 ls -l 查看權限。

chmod [權限] [檔案]
以管理權限執行謹慎

使用授權的管理者權限執行單一指令。

注意僅在必要時使用，先確認指令對系統的影響。

sudo [指令]
02

系統與紀錄檢查

確認程序、資源使用狀態，快速讀取與查找執行紀錄。

7 條
持續追蹤紀錄紀錄

持續顯示文字檔新增的內容。

補充適合觀察服務紀錄；按 Ctrl+C 結束追蹤。

tail -f [檔名]
搜尋檔案文字搜尋

尋找符合關鍵字的行。

補充可加 -n 顯示行號；-i 忽略英文大小寫。

grep "關鍵字" [檔名]
依名稱尋找檔案搜尋

在指定路徑底下搜尋符合名稱的檔案或資料夾。

補充例如：find . -name "*.log" 搜尋目前目錄下的紀錄檔。

find [路徑] -name "[名稱]"
查看磁碟使用量資源

顯示檔案系統的總容量、已用容量與剩餘容量。

補充-h 會將容量轉成較容易閱讀的單位。

df -h
查看記憶體使用量資源

查看系統記憶體及交換空間的使用情況。

補充主要適用於 Linux；macOS（蘋果電腦系統）沒有相同內建指令。

free -h
列出執行中的程序程序

檢視目前的程序及其資源占用資訊。

補充可搭配 grep，例如：ps aux | grep python。

ps aux
即時監看系統資源

動態查看處理器、記憶體與程序的運作狀況。

補充通常按 q 退出；介面依系統版本可能不同。

top
03

網路與遠端連線

檢查網路位址、服務可達性、監聽連接埠與遠端登入。

5 條
查看網路介面位址網路

查看網路介面及 IP（網際網路協定位址）設定。

補充這是 Linux 常見指令；macOS（蘋果電腦系統）可改用 ifconfig。

ip addr
測試基本網路可達性網路

透過網路控制訊息測試目標是否回應。

補充按 Ctrl+C 停止；無回應不一定代表服務無法使用，可能被防火牆阻擋。

ping [IP / 網域]
發出網頁請求網路

向指定網址發出請求並查看回傳內容。

補充例如 curl -I https://example.com 只查看回應標頭。

curl [網址]
查看連接埠與監聽程序連接埠

列出網路套接字、監聽中的 TCP／UDP（傳輸控制協定／使用者資料包協定）連接埠及程序。

補充部分程序資訊需管理權限才能完整查看；主要適用於 Linux。

ss -tulpn
登入遠端主機遠端

透過 SSH（安全殼層協定）連線到遠端系統。

補充把 user 換成帳號、host 換成主機名稱或位址；需要相應的登入憑證。

ssh user@host
04

系統服務管理

查看或控制由 systemd（系統與服務管理程式）管理的服務。

3 條
查看服務狀態服務

檢視服務是否啟動、狀態與最近的執行資訊。

補充例如 systemctl status nginx；此指令適用於使用 systemd 的 Linux。

systemctl status [服務]
重新啟動服務謹慎

停止並重新啟動指定服務。

注意注意：可能短暫中斷連線或處理中的工作，先確認影響範圍。

systemctl restart [服務]
即時追蹤服務紀錄紀錄

查看指定服務新增的系統日誌內容。

補充按 Ctrl+C 結束；若要查看歷史內容可去掉 -f。

journalctl -u [服務] -f
05

Git（版本控制）

追蹤檔案修改、管理分支，以及與遠端儲存庫同步。

12 條
建立本地儲存庫初始化

將目前資料夾初始化為 Git（版本控制）儲存庫。

補充適合新專案；已有儲存庫時通常不需要重複執行。

git init
複製遠端儲存庫同步

將遠端儲存庫及其版本歷史下載到本機。

補充執行後通常會建立同名專案資料夾。

git clone [網址]
查看目前變更檢視

檢視所在分支、已修改與待提交的檔案。

補充修改檔案後先使用這個指令確認狀態。

git status
查看修改差異檢視

顯示尚未加入暫存區的內容差異。

補充要檢查已暫存的修改，改用 git diff --staged。

git diff
暫存目前目錄的修改謹慎

把目前目錄及子目錄的修改加入暫存區。

注意可能包含新增與刪除檔案；先確認 git status，避免納入敏感資料。

git add .
建立本地提交提交

將暫存的修改建立一筆附有說明的版本紀錄。

補充說明建議簡短具體，描述這次改動的目的。

git commit -m "說明"
查看本地分支分支

顯示現有本地分支與目前所在的分支。

補充若要連遠端分支一起查看，可用 git branch -a。

git branch
切換工作分支分支

切換到指定的本地分支。

補充若目前有未提交的修改，可能需要先處理才能切換。

git switch [分支]
取得遠端版本資訊同步

下載遠端的新版本資訊，但不直接合併進目前分支。

補充適合先觀察遠端變動；可搭配 git status 或 git log 查驗。

git fetch
取得並整合遠端更新同步

抓取遠端更新，並依儲存庫設定進行合併或重定基底。

補充可能發生衝突；執行前先確認本地未提交修改。

git pull
推送本地提交同步

把本地提交傳送到設定好的遠端分支。

補充推送前建議先確認分支與提交內容。

git push
快速查看提交歷史檢視

以精簡格式顯示提交識別碼與說明。

補充適合快速辨識近期修改；按 q 可離開分頁顯示。

git log --oneline
06

Docker Compose（容器編排工具）

以專案設定檔啟動、檢查及管理多個容器化服務。

7 條
背景啟動專案服務啟動

依容器編排設定建立並啟動服務，在背景持續執行。

補充通常需要在有 compose.yaml 等設定檔的專案目錄執行。

docker compose up -d
重新建置並啟動建置

先重新建置需要的映像，再建立或更新服務。

補充程式碼或映像建置內容變更後常用；可能造成服務重新建立。

docker compose up -d --build
查看服務容器狀態檢視

列出此專案的容器、狀態及對應連接埠。

補充適合確認各服務是否啟動與是否異常退出。

docker compose ps
持續查看容器紀錄紀錄

連續顯示此專案各服務新增的紀錄。

補充可在後面加服務名稱只看單一服務；按 Ctrl+C 離開。

docker compose logs -f
重新啟動現有服務謹慎

重新啟動專案中已存在的服務容器。

注意不會重新建置映像；設定變更通常需重新建立容器才會生效。

docker compose restart
進入執行中的容器操作

在指定服務的容器內啟動命令列環境。

補充若容器有 bash（命令列殼層），可視需要改用 bash；容器必須正在執行。

docker compose exec [服務] sh
停止並移除專案容器謹慎

停止並移除專案建立的容器與預設網路。

注意預設不會移除具名資料卷；不要隨意加 --volumes，以免刪除資料。

docker compose down
沒有符合的指令請更換搜尋文字，或關閉收藏篩選。
使用提醒：[路徑]、[檔名]、[服務] 等是需自行替換的示意欄位；執行會修改系統的指令前，請先確認目標與影響。收藏及主題偏好只儲存在目前瀏覽器，不會自動跨裝置同步。
