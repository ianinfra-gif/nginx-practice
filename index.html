DevOps（開發維運）常用指令手冊

🐧 Linux（Linux 作業系統）基礎

  • pwd：顯示目前所在的完整目錄路徑
  • cd [路徑]：切換工作目錄
  • ls -la：查看所有檔案、隱藏檔與詳細權限
  • cat [檔名]：查看檔案內容
  • vim [檔名]：編輯文字檔案
  • mkdir [名稱]：建立資料夾
  • cp [來源] [目的地]：複製檔案
  • mv [來源] [目的地]：移動或重新命名檔案
  • rm [檔名]：刪除檔案
  • chmod [權限] [檔案]：修改檔案權限
  • sudo [指令]：使用管理者權限執行指令

🔍 系統與 Log（紀錄）檢查

  • tail -f [檔名]：持續查看最新 Log（紀錄）
  • grep "關鍵字" [檔名]：搜尋檔案內指定文字
  • find [路徑] -name "[名稱]"：搜尋檔案或資料夾
  • df -h：查看磁碟空間
  • free -h：查看記憶體使用量
  • ps aux：查看 Process（程序）
  • top：即時查看 CPU（處理器）、記憶體與 Process（程序）

🌐 網路檢查

  • ip addr：查看網路介面與 IP（網路位址）
  • ping [IP / 網域]：測試網路連線
  • curl [網址]：測試 HTTP（超文字傳輸協定）回應
  • ss -tulpn：查看 Port（連接埠）與使用中的 Process（程序）
  • ssh user@host：SSH（安全遠端連線）登入遠端主機

⚙️ Service（服務）管理

  • systemctl status [服務]：查看 Service（服務）狀態
  • systemctl restart [服務]：重新啟動 Service（服務）
  • journalctl -u [服務] -f：即時查看 Service Log（服務紀錄）

📦 Git（版本控制）

  • git init：初始化 Git（版本控制）Repository（儲存庫）
  • git clone [網址]：複製遠端 Repository（儲存庫）
  • git status：查看目前檔案變更狀態
  • git diff：查看實際修改內容
  • git add .：將全部修改加入 Staging Area（暫存區）
  • git commit -m "說明"：建立 Commit（提交）紀錄
  • git branch：查看 Branch（分支）
  • git switch [分支]：切換 Branch（分支）
  • git fetch：取得遠端最新資料
  • git pull：下載並合併遠端最新內容
  • git push：將本地 Commit（提交）推送到遠端
  • git log --oneline：簡潔查看 Commit（提交）歷史

🐳 Docker Compose（容器編排）

  • docker compose up -d：背景啟動所有 Service（服務）
  • docker compose up -d --build：重新 Build（建置）並啟動服務
  • docker compose ps：查看 Container（容器）運作狀態
  • docker compose logs -f：即時查看 Container Log（容器紀錄）
  • docker compose restart：重新啟動服務
  • docker compose exec [服務] sh：進入正在執行的 Container（容器）
  • docker compose down：停止並移除 Container（容器）服務
常用排錯順序：
git status → docker compose ps → docker compose logs -f → systemctl status → journalctl → ss -tulpn → curl
