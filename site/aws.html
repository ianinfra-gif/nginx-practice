AWS 雲端服務

AWS CLI（亞馬遜雲端命令列介面）與主要雲端資源查詢。

65 條指令與設定·8 個分類·搜尋・複製・收藏
01

身分與環境

設定登入身分、區域與命令列環境。

10 條
確認指令工具版本環境

顯示 AWS CLI（命令列介面）版本。

補充使用 AWS CLI v2（第二代）較符合目前常見官方文件。

aws --version
設定預設憑證與區域憑證

以互動方式設定存取金鑰、預設區域及輸出格式。

注意會寫入本機設定與憑證檔；不要將憑證提交到版本控制系統。可優先使用 SSO（單一登入）或角色。

aws configure
檢查使用中的設定來源環境

查看目前的金鑰、區域與設定值取用來源。

補充只顯示遮罩後的金鑰資訊，適合排查環境變數與設定檔優先順序。

aws configure list
列出本機設定檔環境

查看已設定的命名設定檔。

補充使用 --profile [設定檔] 可指定不同帳號或角色。

aws configure list-profiles
確認目前雲端身分身分

查看目前身分對應的帳號、使用者／角色識別資訊。

補充進行任何資源操作前先確認帳號，避免改錯環境。

aws sts get-caller-identity
透過單一登入取得工作階段身分

開啟登入流程以使用已設定的 IAM Identity Center（身分識別中心）設定檔。

補充必須事先建立對應的 SSO（單一登入）設定檔。

aws sso login --profile [設定檔]
查詢設定檔的預設區域區域

查看指定設定檔內的預設區域。

補充部分服務為全域或採不同端點；區域仍須依服務確認。

aws configure get region --profile [設定檔]
查看指令說明入口環境

開啟 AWS CLI（亞馬遜雲端命令列介面）的內建手冊。

補充可使用 aws [服務] help 查看特定服務。

aws help
檢查指定身分設定身分

查看指定設定檔生效的憑證與區域來源。

補充一般不直接顯示完整機密金鑰，但仍應審慎分享輸出。

aws configure list --profile [設定檔]
列出可查詢區域區域

查看帳號可查詢的 AWS 區域資訊。

補充實際服務可用範圍依帳號與區域而異。

aws ec2 describe-regions
02

EC2（彈性運算雲端）

虛擬主機、安全群組與啟停作業。

10 條
列出虛擬主機查詢

查詢指定區域的 EC2（虛擬主機）實例。

補充回傳內容較多，可搭配 --query 過濾。

aws ec2 describe-instances --region [區域]
查詢單一主機查詢

顯示指定實例的狀態、網路與其他詳細資訊。

補充需具備 describe-instances 權限且區域正確。

aws ec2 describe-instances --instance-ids [實例ID]
檢查主機狀態檢查檢查

查看實例的健康狀態與狀態檢查結果。

補充記得指定 --region [區域]，避免查錯區域。

aws ec2 describe-instance-status --include-all-instances
查看安全群組網路

列出目前區域的入站／出站防火牆規則設定。

補充檢查是否有過於寬鬆的 0.0.0.0/0 對外開放。

aws ec2 describe-security-groups
啟動虛擬主機謹慎

啟動處於停止狀態的 EC2 實例。

注意會產生相應運算費用，啟動前先確認身分與區域。

aws ec2 start-instances --instance-ids [實例ID]
停止虛擬主機謹慎

要求停止指定的 EC2 實例。

注意可能中斷線上服務；部分儲存與相關資源仍可能持續計費。

aws ec2 stop-instances --instance-ids [實例ID]
列出虛擬私有雲網路

查看 VPC（虛擬私有雲）與相關識別資訊。

補充可加 --region 指定區域。

aws ec2 describe-vpcs
列出子網路網路

查看各子網路的 VPC 關係與可用區。

補充屬於唯讀操作。

aws ec2 describe-subnets
列出 EBS 儲存卷儲存

查看附掛與未附掛的區塊儲存裝置。

補充未使用的儲存卷仍可能計費。

aws ec2 describe-volumes
列出彈性 IP 位址網路

查詢已配置的彈性 IP（公用網路位址）。

補充部分閒置或使用中的 IPv4 位址會產生費用。

aws ec2 describe-addresses
03

S3（物件儲存服務）

儲存貯體、物件與資料同步。

11 條
列出可存取的儲存貯體查詢

列出目前身分可列舉的 S3（物件儲存）儲存貯體。

補充可使用 --profile [設定檔] 指定身份；需要對應權限。

aws s3 ls
查看貯體內物件查詢

列出指定貯體或前綴下的檔案物件。

補充S3 使用物件鍵與前綴，不等同一般檔案系統目錄。

aws s3 ls s3://[儲存貯體]/
上傳單一檔案上傳

將本機檔案複製到 S3 儲存貯體。

補充上傳會產生請求與儲存費用，並受貯體政策限制。

aws s3 cp ./report.txt s3://[儲存貯體]/
下載單一檔案下載

將物件複製到目前本機目錄。

補充同名本機檔案可能被覆蓋，先確認下載位置。

aws s3 cp s3://[儲存貯體]/report.txt ./
預覽同步差異預覽

只預覽哪些檔案將被上傳或更新，不實際傳輸。

補充--dryrun（試執行）先確認結果；移除參數後才會真的同步。

aws s3 sync ./site/ s3://[儲存貯體]/site/ --dryrun
同步靜態網站資料謹慎

將本機資料夾同步至 S3 目的路徑。

注意可能變更目的地物件與產生費用；不會預設刪除目的地多餘物件。

aws s3 sync ./site/ s3://[儲存貯體]/site/
查看儲存貯體區域查詢

查詢儲存貯體所在的區域。

補充傳回 null 等值的呈現方式需依舊區域與工具版本解讀。

aws s3api get-bucket-location --bucket [儲存貯體]
建立儲存貯體謹慎

在指定區域建立新的 S3 儲存貯體。

注意會建立雲端資源；命名需全球唯一，儲存與請求可能計費。

aws s3 mb s3://[儲存貯體] --region [區域]
預覽單檔上傳預覽

先列出即將進行的傳輸，不實際上傳。

補充建議確認路徑與帳號後再移除 --dryrun。

aws s3 cp ./[檔案] s3://[儲存貯體]/[路徑]/ --dryrun
預覽鏡像同步與刪除謹慎

顯示資料差異及遠端將被刪除的多餘檔案。

注意若移除 --dryrun，--delete 會刪除目標多餘物件，務必先核對。

aws s3 sync ./[目錄]/ s3://[儲存貯體]/[路徑]/ --delete --dryrun
查詢物件資訊檢視

檢查指定物件的中繼資料與是否存在。

補充需要對應的存取權限。

aws s3api head-object --bucket [儲存貯體] --key [物件鍵]
04

IAM（身分與存取管理）

使用者、角色及權限查詢。

7 條
檢查 IAM 使用者身分

查詢目前 IAM 使用者資訊。

補充假設角色或 SSO 工作階段不是 IAM 使用者時，此指令可能不適用。

aws iam get-user
列出 IAM 使用者查詢

列舉帳號中的 IAM 使用者。

補充需要對應的讀取權限。

aws iam list-users
列出 IAM 角色查詢

查看帳號內可見的 IAM（身分與存取管理）角色。

補充角色是否可使用還取決於信任政策與存取權限。

aws iam list-roles
檢查角色附加政策權限

列出指定角色附加的受管政策。

補充不包含所有內嵌政策；完整有效權限需綜合判斷。

aws iam list-attached-role-policies --role-name [角色名稱]
模擬權限結果權限

評估指定身分對一個操作的 IAM 政策決策。

補充模擬結果無法完全代表實際存取結果，仍可能受其他控制限制。

aws iam simulate-principal-policy --policy-source-arn [身分ARN] --action-names s3:ListAllMyBuckets
查看角色詳細資料權限

取得 IAM（身分與存取管理）角色信任政策等資訊。

補充檢查權限與資源關係時常用。

aws iam get-role --role-name [角色名稱]
查看執行個體設定檔身分

列出可供 EC2 連結的執行個體設定檔。

補充角色與執行個體設定檔不是完全相同的物件。

aws iam list-instance-profiles
05

CloudWatch（監控與日誌）

監控指標、日誌與警示。

7 條
列出日誌群組日誌

查詢目前區域的 CloudWatch Logs（日誌）群組。

補充日誌依區域區分；大型環境需注意分頁。

aws logs describe-log-groups
查看日誌串流日誌

列出指定日誌群組中的日誌串流。

補充適合確認應用程式是否有持續輸出紀錄。

aws logs describe-log-streams --log-group-name [群組名稱]
持續查看最新日誌日誌

持續顯示指定日誌群組的新事件。

補充按 Ctrl+C（控制鍵加 C）結束；讀取日誌可能產生查詢費用。

aws logs tail [群組名稱] --follow
列出監控警示警示

查看目前區域中設定的 CloudWatch（雲端監控）警示。

補充警示狀態不等同故障結論，仍需交叉查核指標。

aws cloudwatch describe-alarms
查看 EC2 指標指標

列舉 EC2（虛擬主機）命名空間下可見的監控指標。

補充可能依服務活動與監控設定而看不到某些指標。

aws cloudwatch list-metrics --namespace AWS/EC2
篩選含錯誤字樣的日誌日誌

從 CloudWatch Logs（雲端日誌）尋找符合過濾條件的紀錄。

補充大量查詢可能耗時並受到 API（程式介面）限制。

aws logs filter-log-events --log-group-name [群組] --filter-pattern "ERROR"
只查看警報中的項目監控

篩選目前為 ALARM（警報）狀態的監控規則。

補充只反映指定區域與身分能看到的資訊。

aws cloudwatch describe-alarms --state-value ALARM
06

CloudFormation（基礎設施範本）

部署、檢視與驗證基礎設施範本。

7 條
列出範本堆疊查詢

查看目前區域曾建立的 CloudFormation（範本部署）堆疊。

補充可能包含已刪除且仍在紀錄保留期內的堆疊。

aws cloudformation list-stacks
檢查部署狀態查詢

查詢指定堆疊的資源與部署狀態摘要。

補充有助於確認部署是否完成或失敗。

aws cloudformation describe-stacks --stack-name [堆疊名稱]
驗證範本基本結構驗證

由 AWS 服務檢查指定範本是否可解析。

補充不保證部署成功，也不會驗證所有執行期權限、配額與費用。

aws cloudformation validate-template --template-body file://template.yaml
查看部署事件紀錄

追查堆疊建立或更新過程的事件紀錄。

補充可搭配堆疊狀態與 CloudWatch 日誌分析。

aws cloudformation describe-stack-events --stack-name [堆疊名稱]
部署範本堆疊謹慎

建立或更新範本描述的 AWS 資源。

注意可能建立付費資源或改動線上環境；先預覽變更集與確認帳號。需要 IAM 資源時應明確處理 capabilities（部署授權能力）。

aws cloudformation deploy --template-file template.yaml --stack-name [堆疊名稱]
查看範本建立的資源部署

列出 CloudFormation（基礎設施範本）堆疊所管理的資源。

補充適合核對資源實際建立情形。

aws cloudformation list-stack-resources --stack-name [堆疊]
啟動資源偏差偵測謹慎

開始檢查堆疊現況是否偏離範本定義。

注意會啟動雲端工作，需接著查詢偵測結果。

aws cloudformation detect-stack-drift --stack-name [堆疊]
07

ECS 與 ECR（容器服務與映像儲存庫）

雲端容器服務、任務及容器映像檔。

7 條
列出 ECS 叢集容器

查看 ECS（彈性容器服務）叢集識別資訊。

補充預設只會查詢目前區域。

aws ecs list-clusters
列出叢集服務容器

檢查指定叢集有哪些長期運作的服務。

補充可搭配 describe-services 了解部署情況。

aws ecs list-services --cluster [叢集]
查看容器服務狀態容器

查看執行中任務數量、部署狀態與事件。

補充適合排查更新失敗或副本不足。

aws ecs describe-services --cluster [叢集] --services [服務]
列出容器任務容器

查看指定叢集的任務 ARN（亞馬遜資源名稱）。

補充若有多個服務，可加 --service-name 過濾。

aws ecs list-tasks --cluster [叢集]
列出 ECR 映像儲存庫映像檔

檢查 ECR（彈性容器登錄服務）的儲存庫。

補充與本機 Docker 映像檔不同。

aws ecr describe-repositories
列出雲端容器映像檔映像檔

取得指定 ECR 儲存庫中的映像標籤與摘要。

補充可用於比對待部署映像檔版本。

aws ecr list-images --repository-name [儲存庫]
取得容器登錄密碼謹慎

輸出短期授權用密碼供 docker login --password-stdin 使用。

注意輸出屬敏感授權資料，不要貼到日誌或共享對話。

aws ecr get-login-password --region [區域]
08

其他常用服務

無伺服器程式、資料庫與遠端工作階段。

6 條
列出無伺服器函式函式

查看 Lambda（無伺服器運算服務）函式與基本資訊。

補充只顯示目前身分與區域可見的資源。

aws lambda list-functions
查詢指定函式函式

取得函式設定與部署套件位置資訊。

補充輸出可能包含環境變數等敏感設定。

aws lambda get-function --function-name [函式]
執行指定函式謹慎

同步觸發 Lambda 函式並將回應寫入檔案。

注意此操作可能更動雲端資料並產生費用，先了解函式行為。

aws lambda invoke --function-name [函式] output.json
列出關聯式資料庫資料庫

查看 RDS（關聯式資料庫服務）執行個體狀態。

補充資料庫在停止後仍可能有相關儲存費用。

aws rds describe-db-instances
開啟受控主機工作階段遠端

透過 Systems Manager（系統管理服務）連接受管理的實例。

補充需安裝工作階段管理外掛並具有對應權限。

aws ssm start-session --target [實例ID]
列出 Kubernetes 叢集容器

查詢 EKS（彈性 Kubernetes 服務）叢集。

補充叢集建立後即可能產生管理費用。

aws eks list-clusters
找不到指令
