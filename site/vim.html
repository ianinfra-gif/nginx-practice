Vim 編輯器

模式、編輯、導覽、搜尋、分割視窗與快速操作。

70 條指令與設定·6 個分類·搜尋・複製・收藏
01

模式與進入

開啟編輯器、切換操作模式。

12 條
開啟檔案開啟

從終端機以 Vim（文字編輯器）開啟或建立檔案。

補充這是終端機指令，其餘多數快捷鍵須在 Vim 內使用。

vim [檔名]
回到一般模式模式

離開插入或視覺模式，返回一般模式。

補充不確定目前模式時，先按 Esc（跳脫鍵）。

Esc
在游標前插入輸入

從一般模式進入插入模式，開始輸入文字。

補充需要先在一般模式按 i。

i
在游標後插入輸入

從一般模式進入插入模式，從目前字元後輸入。

補充與 i 的差異是插入位置。

a
下一行新增空白行輸入

在目前行下方新增一行並進入插入模式。

補充大寫 O 則在上方新增。

o
進入字元視覺模式選取

開始選取字元範圍。

補充大寫 V 選整行；Ctrl+v 選矩形區塊。

v
進入命令列模式模式

在一般模式輸入冒號，以執行儲存、結束等命令。

補充例如 :w 或 :q，最後按 Enter（輸入鍵）確認。

:
在行首插入文字輸入

從一般模式切換到插入模式並跳到本行第一個非空白字元。

補充大寫 I 與小寫 i 的插入位置不同。

I
在行尾插入文字輸入

跳到行尾並進入插入模式。

補充適合快速補充目前行尾。

A
在目前行上方新增一行輸入

插入空白行並進入插入模式。

補充與小寫 o 在下方插入不同。

O
進入整行視覺模式選取

以整行為單位選取文字。

補充選取後可使用 y 複製或 d 刪除。

V
進入區塊視覺模式選取

以矩形區塊選取多行欄位。

補充部分終端機會攔截快捷鍵，需查看終端機設定。

Ctrl+v
02

游標與導覽

單字、行、頁面及檔案移動。

13 條
移動游標移動

分別向左／下／上／右移動一格。

補充也可使用方向鍵，但熟悉 hjkl 後更不必離開主要鍵位。

h / j / k / l
前往下一個單字單字

移到下一個單字開頭。

補充b 返回上一個單字開頭；e 移到單字結尾。

w
移到行首行內

移到目前行的第 1 欄。

補充^（插入號）可跳到本行第一個非空白字元。

0
移到行尾行內

跳到目前行的最後一個字元。

補充常搭配 d$ 刪除到行尾。

$
跳到檔案開頭跳轉

移動到檔案第一行。

補充可輸入 20gg 跳到第 20 行。

gg
跳到檔案結尾跳轉

移動到檔案最後一行。

補充例如 20G 跳到第 20 行。

G
半頁捲動捲動

向下／向上捲動半個畫面。

補充Ctrl+f 與 Ctrl+b 則分別向下／向上捲動整頁。

Ctrl+d / Ctrl+u
移動到上一個單字開頭移動

向前跳到單字邊界。

補充通常在一般模式使用。

b
移到目前／下一單字結尾移動

依 Vim 的單字邊界移動。

補充可與編輯指令組合。

e
移到行首非空白字元移動

跳過行首縮排，停在第一個非空白字元。

補充0 會移到真正的行首。

^
跳到指定行定位

例如 120G 前往第 120 行。

補充也可以用 :120。

[數字]G
跳到成對符號移動

在括號等配對符號間跳轉。

補充適合檢查程式區塊。

%
整頁捲動移動

向前或向後捲動一頁。

補充與 Ctrl+d、Ctrl+u 的半頁捲動不同。

Ctrl+f / Ctrl+b
03

編輯與復原

插入、刪除、複製、貼上、修改與重做。

16 條
刪除目前字元刪除

刪除游標所在字元。

補充可搭配數字，例如 3x 刪除三個字元。

x
刪除整行刪除

刪除目前整行，內容同時進入 Vim 暫存器。

補充例如 3dd 刪除三行；可用 p 重新貼上。

dd
刪除一個單字範圍刪除

從游標位置刪除至下一個單字開頭。

補充操作取決於游標位置，注意空白字元的涵蓋範圍。

dw
複製目前整行複製

將目前行放入 Vim 暫存器，不刪除原內容。

補充例如 3yy 複製三行。

yy
貼上貼上

p 貼在游標後方或目前行下方；P 則貼在前方或上方。

補充行型與字元型複製內容的貼上行為有所不同。

p / P
復原修改復原

撤銷上一個編輯變更。

補充可連按 u 多次回復。

u
重做修改復原

重新套用剛才撤銷的變更。

補充與 u（復原）相對。

Ctrl+r
修改到下一個單字開頭修改

刪除目前游標到單字尾端的範圍，並進入插入模式。

補充對游標所在的位置敏感；可搭配 ciw 修改整個單字。

cw
全檔文字取代謹慎

在整個檔案中將每一行符合的文字全部替換。

注意可能一次改很多處；加 c 可逐筆確認（:%s/舊/新/gc）。

:%s/舊文字/新文字/g
刪除到行尾編輯

從目前游標位置刪到目前行尾。

補充相當於 d$。

D
修改到行尾編輯

刪除到行尾後進入插入模式。

補充相當於 c$。

C
修改目前單字編輯

刪除游標所在單字後進入插入模式。

補充常用於快速替換變數名稱。

ciw
複製一個單字範圍複製

從目前游標位置複製到下一個單字邊界。

補充若要複製整行可用 yy。

yw
在游標前貼上貼上

將暫存文字貼至目前位置之前。

補充小寫 p 則貼在游標之後。

P
重複上一個修改編輯

重複最近一次可重複的編輯動作。

補充適合大量規則性文字修改。

.
增加或減少縮排格式

將目前行向右或向左縮排。

補充在視覺選取後也可用 > 或 <。

>> / <<
04

搜尋與定位

文字搜尋、取代、行號與定位。

10 條
向下搜尋文字搜尋

在一般模式輸入 / 加文字，再按 Enter（輸入鍵）開始搜尋。

補充按 n 尋找下一筆；N 反方向尋找。

/關鍵字
向上搜尋文字搜尋

在一般模式輸入 ? 加文字，從目前位置反方向搜尋。

補充後續 n 繼續同方向，N 反方向。

?關鍵字
跳轉搜尋結果搜尋

n 移到下一個相同方向的結果，N 往相反方向。

補充配合 / 或 ? 使用。

n / N
逐筆確認全檔取代修改

全檔搜尋 old，對每個取代 new 的項目詢問確認。

補充比直接全檔取代更適合不熟悉的設定檔。

:%s/old/new/gc
顯示行號顯示

顯示每一行的行號。

補充永久設定可寫入個人 Vim 設定檔。

:set number
顯示相對行號顯示

呈現每行距離游標的相對行數。

補充適合搭配 5j、4k 等相對移動。

:set relativenumber
搜尋游標所在單字搜尋

向下尋找目前游標附近的單字。

補充按 n 跳往下一個結果。

*
取消搜尋結果亮顯搜尋

暫時清除搜尋的高亮狀態。

補充不會刪除搜尋歷史。

:nohlsearch
搜尋時忽略大小寫搜尋

設定搜尋符合時不區分英文字母大小寫。

補充只影響目前設定範圍；可搭配 smartcase。

:set ignorecase
顯示空白與換行記號檢視

幫助檢查 Tab（定位字元）、尾端空白等格式。

補充可用 :set nolist 取消。

:set list
05

儲存與離開

儲存、關閉、另存與緩衝區。

10 條
儲存目前檔案儲存

將目前緩衝區內容寫入檔案。

補充若沒有寫入權限會失敗，請勿直接假設已儲存。

:w
離開目前視窗離開

在沒有未儲存變更時離開目前視窗。

補充有未存變更時 Vim 通常會提醒，不會直接放棄。

:q
儲存並離開儲存

先儲存檔案，再離開目前編輯視窗。

補充與 ZZ 功能相近，但 ZZ 通常僅在有修改時寫入。

:wq
放棄修改並離開謹慎

強制離開目前視窗，不儲存未寫入內容。

注意未儲存變更可能遺失，操作前先確認。

:q!
另存到其他檔案儲存

將目前內容寫入指定新路徑。

補充此操作不一定將編輯緩衝區切換成新檔案。

:w [新檔名]
開啟另一個檔案檔案

在目前視窗編輯另一個指定檔案。

補充有未儲存變更時 Vim 通常會阻擋切換。

:e [檔名]
關閉所有視窗離開

要求退出所有開啟的視窗。

補充若有未儲存修改，Vim 會阻止安全退出。

:qa
儲存全部已修改緩衝區儲存

將可寫入的已修改內容一次儲存。

補充多檔同時編輯時使用前先確認檔案。

:wa
列出目前緩衝區檢視

查看已開啟與曾載入的檔案緩衝區。

補充可搭配 :bnext 和 :bprevious。

:ls
切換到下一個緩衝區導航

在多個開啟的檔案之間移動。

補充可用 :bprevious 反向切換。

:bnext
06

視窗與輔助

分割編輯、說明與其他常見工具。

9 條
水平分割視窗視窗

在目前編輯視窗建立水平分割。

補充可省略檔名以檢視同一檔案。

:split [檔名]
垂直分割視窗視窗

在目前編輯視窗建立左右分割。

補充方便對照兩個設定檔。

:vsplit [檔名]
切換到下一個視窗視窗

在已分割的編輯視窗之間切換。

補充先按 Ctrl+w，再按 w。

Ctrl+w w
查看內建說明說明

開啟 Vim 的指定主題說明文件。

補充例如 :help :w 查閱儲存指令。

:help [主題]
啟用貼上模式設定

暫時減少自動縮排對外部貼上文字的干擾。

補充貼上後執行 :set nopaste 恢復；新式終端機支援 bracketed paste（括號貼上）時可能不需要。

:set paste
切換到方向上的視窗視窗

以 Vim 常用移動鍵定位到相鄰分割視窗。

補充適用於一般模式。

Ctrl+w h / j / k / l
關閉貼上模式設定

恢復一般輸入時的自動縮排等編輯行為。

補充搭配 :set paste 使用。

:set nopaste
將 Tab 鍵轉成空白設定

依目前縮排寬度輸入空白。

補充需配合 shiftwidth、tabstop 等設定。

:set expandtab
設定縮排寬度設定

指定使用 > 或 < 縮排時的預設寬度。

補充數值 4 僅為示範，可按專案規範調整。

:set shiftwidth=4
找不到指令

請調整搜尋條件。
