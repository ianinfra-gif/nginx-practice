Git 版本控制

提交、分支、遠端協作、衝突處理與歷史還原。

48 條指令與設定·4 個分類·搜尋・複製・收藏
01

儲存庫與檢視

初始化、狀態、差異、提交歷史與遠端。

17 條
建立本地儲存庫初始化

將目前資料夾初始化為 Git（版本控制）儲存庫。

補充適合新專案；已有儲存庫時通常不需要重複執行。

git init
複製遠端儲存庫同步

將遠端儲存庫及其版本歷史下載到本機。

補充執行後通常會建立同名專案資料夾。

git clone [網址]
查看目前變更檢視

檢視所在分支、已修改與待提交的檔案。

補充修改檔案後先使用這個指令確認狀態。

git status
查看修改差異檢視

顯示尚未加入暫存區的內容差異。

補充要檢查已暫存的修改，改用 git diff --staged。

git diff
暫存目前目錄的修改謹慎

把目前目錄及子目錄的修改加入暫存區。

注意可能包含新增與刪除檔案；先確認 git status，避免納入敏感資料。

git add .
建立本地提交提交

將暫存的修改建立一筆附有說明的版本紀錄。

補充說明建議簡短具體，描述這次改動的目的。

git commit -m "說明"
快速查看提交歷史檢視

以精簡格式顯示提交識別碼與說明。

補充適合快速辨識近期修改；按 q 可離開分頁顯示。

git log --oneline
查看 Git 版本環境

確認目前安裝的 Git（版本控制工具）版本。

補充有助於比對指令是否受版本限制。

git --version
查看設定與來源設定

列出有效設定及來源檔案。

補充輸出可能包含個人資料或憑證助手設定，分享前檢查。

git config --list --show-origin
設定提交作者名稱設定

設定目前使用者預設的提交作者名稱。

補充這不會變更遠端帳號名稱。

git config --global user.name "[名稱]"
設定提交作者信箱設定

設定新提交預設使用的電子郵件。

補充依專案需求可使用不同身分與隱私信箱。

git config --global user.email "[電子郵件]"
查看已暫存差異檢視

比較暫存區與最後一次提交的差異。

補充提交前確認內容的重要步驟。

git diff --staged
簡潔查看工作樹狀態檢視

用簡短符號標示已修改、新增與未追蹤檔案。

補充適合大型專案快速檢視。

git status --short
查看分支關聯圖檢視

使用文字圖顯示本地各參照的提交歷史。

補充有助於了解合併與分支狀態。

git log --oneline --graph --decorate --all
查看指定提交檢視

檢視單次提交的差異與內容。

補充可先用 git log 找到提交識別碼。

git show [提交ID]
列出遠端儲存庫遠端

查看已設定的遠端名稱與網址。

補充公開輸出前確認網址未包含敏感憑證。

git remote -v
查詢忽略規則來源檢視

顯示是哪條 .gitignore（忽略檔案規則）導致檔案被忽略。

補充若檔案已被追蹤，可加 --no-index 測試規則。

git check-ignore -v [檔案]
02

分支與遠端

分支、同步、推送、追蹤與標籤。

15 條
推送本地提交同步

把本地提交傳送到設定好的遠端分支。

補充推送前建議先確認分支與提交內容。

git push
取得並整合遠端更新同步

抓取遠端更新，並依儲存庫設定進行合併或重定基底。

補充可能發生衝突；執行前先確認本地未提交修改。

git pull
取得遠端版本資訊同步

下載遠端的新版本資訊，但不直接合併進目前分支。

補充適合先觀察遠端變動；可搭配 git status 或 git log 查驗。

git fetch
切換工作分支分支

切換到指定的本地分支。

補充若目前有未提交的修改，可能需要先處理才能切換。

git switch [分支]
查看本地分支分支

顯示現有本地分支與目前所在的分支。

補充若要連遠端分支一起查看，可用 git branch -a。

git branch
列出本地與遠端分支分支

顯示本地分支及遠端追蹤分支。

補充先執行 git fetch 才能取得最新遠端參照。

git branch -a
建立並切換分支分支

從目前提交建立新的工作分支。

補充適合在修改功能前隔離工作。

git switch -c [新分支]
更新並清理遠端參照遠端

取得所有遠端資訊，移除已不存在的遠端追蹤參照。

補充不會刪除本地實體工作分支。

git fetch --all --prune
只允許快轉同步遠端

當本地沒有與遠端分岔時更新分支。

補充遇到分岔會停止，不會自動新增合併提交。

git pull --ff-only
推送並設定追蹤分支遠端

首次推送本地分支到 origin（預設遠端名稱）。

補充確認分支名稱與存取權限。

git push -u origin [分支]
刪除已合併的本地分支謹慎

要求 Git 確認分支已適當合併才刪除。

注意請先切換到其他分支；刪除後工作樹不會自動還原。

git branch -d [分支]
建立附註標籤版本

標示重要發行版或里程碑。

補充標籤不會自動隨一般 push 上傳。

git tag -a [標籤] -m "[說明]"
推送單一標籤版本

將指定標籤上傳到遠端。

補充常用於標記正式發行版本。

git push origin [標籤]
切回上一個分支分支

返回之前切換過的分支。

補充工作目錄修改可能影響切換。

git switch -
顯示目前分支名稱分支

只輸出所在分支，方便快速確認。

補充分離 HEAD（目前指向）狀態可能沒有分支名稱。

git branch --show-current
03

暫存、還原與修正

暫存未完成工作、復原修改與修正提交。

9 條
逐區塊挑選暫存內容暫存

逐段檢視修改，選擇哪些內容加入暫存。

補充避免一次提交不相關的改動。

git add -p
取消暫存但保留修改暫存

把指定檔案從暫存區移回工作目錄修改狀態。

補充不會丟棄工作目錄中的修改。

git restore --staged [檔案]
丟棄未暫存的修改謹慎

把指定檔案還原成索引中的版本。

注意未提交的工作目錄修改會消失，請先確認。

git restore [檔案]
暫存未完成工作暫存

將目前追蹤檔案的修改暫時收起。

補充預設不包含未追蹤檔案，必要時加 -u。

git stash push -m "[說明]"
列出暫存工作暫存

顯示目前儲存的暫存項目。

補充可搭配 stash show 檢視內容。

git stash list
取回最近暫存工作暫存

套用最近一份暫存工作，成功後移出暫存清單。

補充若產生衝突，可能保留暫存項目，須人工檢查。

git stash pop
修正最後一次提交謹慎

將目前暫存修改補入上一筆提交。

注意會重寫提交識別碼，不宜任意修改他人已依賴的遠端歷史。

git commit --amend
查看本地參照歷史還原

找回近期 HEAD（目前指向）或分支曾經的位置。

補充適合調查意外切換或重設後的提交。

git reflog
建立反向提交謹慎

新增一筆提交以反轉指定提交的變更。

注意適合處理已推送提交；可能發生衝突。

git revert [提交ID]
04

合併與衝突

合併、變基及衝突時的安全處理。

7 條
合併指定分支謹慎

將指定分支歷史合併到目前分支。

注意先檢查工作目錄是否乾淨，並確認合併方向。

git merge [分支]
放棄進行中的合併還原

在合併衝突期間盡可能還原到合併前狀態。

補充若原先工作目錄已有其他改動，需謹慎確認。

git merge --abort
在指定分支上重播提交謹慎

重新排列目前分支的提交基礎。

注意會改寫提交歷史，不宜任意重寫共用分支。

git rebase [分支]
繼續處理變基協作

解決衝突並完成暫存後，繼續重播提交。

補充先解決衝突，再以 git add 標記完成。

git rebase --continue
取消進行中的變基還原

回到此次 rebase（變基）開始前的狀態。

補充適合不確定衝突如何處理時。

git rebase --abort
挑選單一提交套用謹慎

把另一分支的特定提交套到目前分支。

注意可能產生衝突或重複套用相同變更。

git cherry-pick [提交ID]
檢查常見空白問題檢視

找出變更中的尾端空白等格式錯誤。

補充提交前可搭配檢查。

git diff --check
找不到指令

請調整搜尋條件。
