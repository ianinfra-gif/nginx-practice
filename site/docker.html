Docker 與 Compose 容器

映像檔、容器、網路、儲存空間與多服務管理。

53 條指令與設定·4 個分類·搜尋・複製・收藏
01

環境與映像檔

確認 Docker（容器平台）、下載與管理映像檔。

9 條
查看 Docker 版本環境

確認 Docker（容器平台）指令版本。

補充並不代表容器執行環境一定已啟動。

docker --version
查看用戶端與伺服端版本環境

顯示 Docker 客戶端與守護程序的版本資訊。

補充若無法連到守護程序會顯示連線錯誤。

docker version
檢查容器執行環境環境

查看儲存驅動程式、資源及伺服端資訊。

補充可先用來確認 Docker Engine（容器引擎）是否正常。

docker info
列出本機映像檔映像檔

顯示目前快取的容器映像檔及標籤。

補充TAG（標籤）不是更新檢查機制。

docker image ls
下載指定映像檔映像檔

從映像檔登錄服務取得 Nginx 輕量穩定分支。

補充生產環境宜固定已驗證的具體版本或摘要。

docker pull nginx:stable-alpine
查看映像檔詳細資料檢視

顯示映像檔的識別碼、設定與層級。

補充可查環境變數、進入點與平台。

docker image inspect [映像檔]
查看映像檔建置歷史檢視

列出映像檔各層與建立指令摘要。

補充不保證能還原原始建置檔案。

docker history [映像檔]
建置本機映像檔建置

以目前目錄的 Dockerfile（容器建置檔）建立映像檔。

補充需注意 .dockerignore（建置排除設定）與機密檔案。

docker build -t [名稱]:[版本] .
建立額外映像檔標籤映像檔

替同一映像檔增加一個標籤。

補充不會複製映像檔的資料層。

docker tag [來源映像檔] [新名稱]:[版本]
02

容器操作

建立、查看、操作容器與讀取日誌。

15 條
列出執行中的容器容器

顯示容器名稱、狀態、影像與埠號映射。

補充與 docker ps -a 可比對已停止容器。

docker ps
列出所有容器容器

包括已停止及曾建立過的容器。

補充可搭配 docker logs 檢查失敗紀錄。

docker ps -a
測試容器執行測試

下載並執行官方測試映像檔，結束後移除容器。

補充首次執行可能需要連線下載映像檔。

docker run --rm hello-world
背景啟動網站容器謹慎

將主機 8080 連接埠對應到容器 80 連接埠。

注意預設可能對所有主機介面開放，先檢查網路政策。

docker run -d --name [名稱] -p 8080:80 nginx:stable-alpine
查看容器最後百筆紀錄紀錄

不持續追蹤，只輸出目前紀錄。

補充避免將包含密碼或憑證的日誌公開分享。

docker logs --tail 100 [容器]
持續追蹤容器日誌紀錄

保持連線並顯示容器的新輸出。

補充按 Ctrl+C 結束追蹤，不會停止容器。

docker logs -f [容器]
查看容器設定與狀態檢視

顯示容器掛載、網路、啟動參數等資訊。

補充設定中可能包含環境變數機密。

docker inspect [容器]
即時監控容器資源資源

顯示處理器、記憶體與網路使用量。

補充按 Ctrl+C 停止監控。

docker stats
進入容器終端機容器

在執行中的容器內開啟 sh（命令列殼層）。

補充不是每個映像檔都包含 Bash（命令列殼層）。

docker exec -it [容器] sh
從容器複製檔案檔案

將檔案複製到主機。

補充適合取回設定或產出檔案。

docker cp [容器]:[來源] [本機目的地]
停止單一容器謹慎

先送出正常停止訊號，逾時後可能強制結束。

注意目前提供的服務可能短暫中斷。

docker stop [容器]
啟動既有容器容器

啟動已建立但停止的容器。

補充不會重建映像檔或更新版本。

docker start [容器]
重新啟動容器謹慎

停止後再啟動既有容器。

注意不會取得新的映像檔，服務會短暫中斷。

docker restart [容器]
移除已停止容器謹慎

刪除容器的可寫層與中繼資料。

注意非掛載的容器內資料可能遺失。

docker rm [容器]
查詢對外連接埠網路

查看主機埠號與容器連接埠的對應。

補充僅顯示已發布的埠號映射。

docker port [容器]
03

儲存與網路

持久化資料、網路與資源使用狀態。

7 條
列出資料卷儲存

顯示由 Docker 管理的資料卷。

補充資料卷通常在容器移除後仍會保留。

docker volume ls
檢查資料卷詳細資訊儲存

可查看掛載點、驅動與標籤。

補充主機上的實際儲存位置依平台而異。

docker volume inspect [資料卷]
列出 Docker 網路網路

查看預設與使用者建立的容器網路。

補充Compose 專案通常建立自己的網路。

docker network ls
檢查容器網路詳細資訊網路

顯示子網、容器連結與設定。

補充有助於排查容器間 DNS 與連線。

docker network inspect [網路]
查看 Docker 磁碟使用量資源

顯示映像檔、容器、資料卷與建置快取佔用。

補充適合清理前先盤點。

docker system df
清理未被標記使用的映像檔謹慎

刪除懸空映像檔，通常需要確認。

注意不會清理所有未使用映像檔；執行前先看列表。

docker image prune
移除已停止容器謹慎

移除所有已停止容器。

注意可能刪除容器可寫層資料，先確認是否需要保留。

docker container prune
04

Docker Compose（容器編排）

啟動、建置、診斷與更新多個服務。

22 條
背景啟動專案服務啟動

依容器編排設定建立並啟動服務，在背景持續執行。

補充通常需要在有 compose.yaml 等設定檔的專案目錄執行。

docker compose up -d
重新建置並啟動建置

先重新建置需要的映像，再建立或更新服務。

補充程式碼或映像建置內容變更後常用；可能造成服務重新建立。

docker compose up -d --build
查看服務容器狀態檢視

列出此專案的容器、狀態及對應連接埠。

補充適合確認各服務是否啟動與是否異常退出。

docker compose ps
持續查看容器紀錄紀錄

連續顯示此專案各服務新增的紀錄。

補充可在後面加服務名稱只看單一服務；按 Ctrl+C 離開。

docker compose logs -f
重新啟動現有服務謹慎

重新啟動專案中已存在的服務容器。

注意不會重新建置映像；設定變更通常需重新建立容器才會生效。

docker compose restart
進入執行中的容器操作

在指定服務的容器內啟動命令列環境。

補充若容器有 bash（命令列殼層），可視需要改用 bash；容器必須正在執行。

docker compose exec [服務] sh
停止並移除專案容器謹慎

停止並移除專案建立的容器與預設網路。

注意預設不會移除具名資料卷；不要隨意加 --volumes，以免刪除資料。

docker compose down
查看編排工具版本環境

確認 Compose（容器編排工具）版本。

補充使用 docker compose 而非舊式 docker-compose 指令。

docker compose version
驗證並展開設定檢查

檢查設定檔的合併及變數替換。

補充輸出可能包含解開的環境變數值，分享前先檢查。

docker compose config
列出專案服務名稱檢視

從有效設定中列出服務名稱。

補充比猜測服務名稱更可靠。

docker compose config --services
取得服務映像檔更新

下載 Compose 設定引用的映像檔。

補充不會自動替換正在執行的容器，需重新啟動並建立。

docker compose pull
重建服務容器謹慎

依目前設定重新建立並啟動服務。

注意可能短暫中斷服務；資料卷與掛載需先核對。

docker compose up -d --force-recreate
查看指定服務日誌紀錄

只顯示最後一百筆，不持續追蹤。

補充不指定服務時可查看整個專案的日誌。

docker compose logs --tail=100 [服務]
在服務容器內執行指令容器

對已執行的服務容器發出命令。

補充容器必須執行中；指令必須存在於容器內。

docker compose exec [服務] [指令]
建立一次性服務容器謹慎

執行指定服務的臨時工作並在完成後移除容器。

注意可能執行服務預設程式與觸及掛載資料，先確認。

docker compose run --rm [服務] [指令]
暫停運作並保留容器謹慎

停止 Compose 服務，但不移除容器。

注意使用 up 或 start 可以重新啟動。

docker compose stop
移除舊版孤兒服務謹慎

停止並移除目前專案的服務及已不再定義的孤兒容器。

注意不會預設刪除具名資料卷；確認服務影響。

docker compose down --remove-orphans
列出 Compose 專案檢視

查看目前已建立的多服務專案。

補充比單純列出容器更容易分辨專案。

docker compose ls
建置服務映像檔建置

依設定檔中的 build（建置來源）重新建立映像檔。

補充不會自動替換已執行容器，通常需搭配 up。

docker compose build
啟動指定服務啟動

啟動單個服務及其必要相依服務。

補充依設定可能仍會啟動相依服務。

docker compose up -d [服務]
追蹤指定服務日誌紀錄

持續查看特定服務的新輸出。

補充按 Ctrl+C 只停止追蹤，不會停止容器。

docker compose logs -f [服務]
查看 Compose 服務映像檔映像檔

顯示目前服務使用的映像檔版本。

補充更新後可用此指令比對是否已換版。

docker compose images
找不到指令

請調整搜尋條件。
