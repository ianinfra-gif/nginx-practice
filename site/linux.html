01

檔案與目錄

路徑、檔案、文字處理、存取權限與壓縮。

34 條
查看目前位置路徑

顯示目前工作目錄的完整路徑。

補充要確認自己正在哪個資料夾時先用它。

pwd
切換目錄路徑

前往指定資料夾，改變後續指令的執行位置。

補充例如：cd /var/log；cd .. 返回上一層；cd ~ 回家目錄。

cd [路徑]
列出詳細檔案資訊檢視

同時顯示隱藏檔、權限、擁有者及檔案資訊。

補充-l 顯示詳細資訊；-a 包含以點號開頭的隱藏檔。

ls -la
讀取檔案內容檢視

將文字檔完整內容顯示在終端機。

補充適合較短的文字檔；過長的檔案可改用 less [檔名] 分頁查看。

cat [檔名]
編輯文字檔編輯

使用 Vim（文字編輯器）開啟或建立檔案。

補充按 i 開始輸入；Esc 離開輸入模式；:wq 儲存離開；:q! 放棄修改離開。

vim [檔名]
建立資料夾檔案

在目前目錄建立新資料夾。

補充建立多層資料夾可使用 mkdir -p [路徑]。

mkdir [名稱]
複製檔案檔案

複製檔案到指定位置。

補充若來源是資料夾，通常需加 -r；留意同名檔案可能被覆蓋。

cp [來源] [目的地]
移動或重新命名檔案

把檔案或資料夾移至其他位置，也能直接改名。

補充目標已有同名檔案時可能被覆蓋；可用 mv -i 先提示確認。

mv [來源] [目的地]
刪除檔案謹慎

從檔案系統刪除指定檔案。

注意通常不會進入資源回收筒。避免不明確的 rm -rf 操作。

rm [檔名]
修改檔案權限權限

調整檔案或目錄的讀取、寫入、執行權限。

補充例如 chmod +x script.sh 讓腳本可執行；修改前先用 ls -l 查看權限。

chmod [權限] [檔案]
以管理權限執行謹慎

使用授權的管理者權限執行單一指令。

注意僅在必要時使用，先確認指令對系統的影響。

sudo [指令]
以易讀方式列出檔案檢視

顯示大小、權限與修改時間等資訊。

補充-h 搭配 -l 將容量顯示為 K、M、G 等單位。

ls -lh
顯示實際實體路徑路徑

顯示解析符號連結後的目前目錄。

補充與一般 pwd 的邏輯路徑可能不同。

pwd -P
建立空檔或更新時間檔案

檔案不存在時建立；存在時更新存取與修改時間。

補充不會清空既有檔案。

touch [檔名]
建立多層目錄檔案

一次建立不存在的父層目錄。

補充適合建立巢狀專案資料夾。

mkdir -p [路徑]
保留屬性複製檔案

盡可能保留權限、時間與符號連結並複製目錄。

補充不同檔案系統可能無法完整保留所有屬性。

cp -a [來源] [目的地]
確認後刪除檔案謹慎

刪除前詢問是否執行。

注意刪除後一般不會進入資源回收筒。

rm -i [檔名]
查看資料夾權限權限

查看目錄本身的權限及擁有者。

補充與 ls -l [資料夾] 列出內部內容不同。

ls -ld [資料夾]
變更擁有者與群組謹慎

修改檔案的所有權。

注意通常需要管理權限，請確認帳號與群組存在。

chown [使用者]:[群組] [檔案]
建立符號連結檔案

建立指向其他檔案或目錄的捷徑式連結。

補充移動目標後，連結可能失效。

ln -s [目標路徑] [連結名稱]
查看完整檔案資訊檢視

檢視檔案大小、權限、時間戳記等。

補充Linux 與 macOS 的輸出格式略有不同。

stat [檔案]
查看前二十行檢視

只讀取檔案開頭部分。

補充適合快速確認內容格式。

head -n 20 [檔名]
查看最後五十行檢視

查看檔案最新的固定行數。

補充不會持續追蹤；若要持續追蹤可用 tail -f。

tail -n 50 [檔名]
分頁閱讀檔案檢視

上下捲動大型文字檔，不需一次輸出全部內容。

補充按 q 退出、/ 進行搜尋。

less [檔名]
計算行數檢視

顯示文字檔的行數。

補充可快速統計日誌或清單。

wc -l [檔名]
建立 gzip 壓縮檔壓縮

將指定目錄打包並壓縮。

補充壓縮檔將寫入目前工作目錄。

tar -czf [封存檔].tar.gz [目錄]
解開 gzip 壓縮檔謹慎

將壓縮檔內容解壓至目前資料夾。

注意先用 tar -tzf [封存檔].tar.gz 預覽內容及路徑。

tar -xzf [封存檔].tar.gz
預覽 ZIP 壓縮檔壓縮

列出壓縮檔內容，不解壓縮。

補充適合先檢查檔案路徑。

unzip -l [檔案].zip
解開 ZIP 壓縮檔壓縮

解壓縮至指定目錄。

補充同名檔案可能遇到覆蓋確認，先預覽內容。

unzip [檔案].zip -d [目的地]
列出檔案詳細資訊檢視

顯示權限、擁有者、大小與修改時間。

補充ll 並非標準指令，通常是 Shell（命令列）別名；ls -l 較通用。

ls -l
檢查 ll 是否有定義檢視

確認 ll 是別名、函式還是可執行命令。

補充部分系統沒有 ll；可直接使用 ls -l。

type ll
設定常見可執行權限權限

擁有者可讀寫執行，群組與其他人可讀與執行。

補充勿隨意替機密檔案開放其他使用者存取。

chmod 755 [路徑]
限制只有擁有者可讀寫權限

常用於私人設定檔與 SSH（安全遠端連線）私鑰。

補充先確認檔案擁有者正確。

chmod 600 [檔案]
尋找指定副檔名搜尋

遞迴列出路徑下副檔名為 .log 的一般檔案。

補充-type f 會排除資料夾。

find [目錄] -type f -name "*.log"
02

資源與紀錄

處理程序、磁碟容量、日誌與系統資訊。

23 條
持續追蹤紀錄紀錄

持續顯示文字檔新增的內容。

補充適合觀察服務紀錄；按 Ctrl+C 結束追蹤。

tail -f [檔名]
搜尋檔案文字搜尋

尋找符合關鍵字的行。

補充可加 -n 顯示行號；-i 忽略英文大小寫。

grep "關鍵字" [檔名]
依名稱尋找檔案搜尋

在指定路徑底下搜尋符合名稱的檔案或資料夾。

補充例如：find . -name "*.log" 搜尋目前目錄下的紀錄檔。

find [路徑] -name "[名稱]"
查看磁碟使用量資源

顯示檔案系統的總容量、已用容量與剩餘容量。

補充-h 會將容量轉成較容易閱讀的單位。

df -h
查看記憶體使用量資源

查看系統記憶體及交換空間的使用情況。

補充主要適用於 Linux；macOS（蘋果電腦系統）沒有相同內建指令。

free -h
列出執行中的程序程序

檢視目前的程序及其資源占用資訊。

補充可搭配 grep，例如：ps aux | grep python。

ps aux
即時監看系統資源

動態查看處理器、記憶體與程序的運作狀況。

補充通常按 q 退出；介面依系統版本可能不同。

top
查詢目錄佔用容量資源

統計指定目錄的總大小。

補充與 df -h 的整個檔案系統使用量不同。

du -sh [目錄]
找出大型子目錄資源

列出指定目錄下一層的容量。

補充--max-depth 為 GNU 工具選項；macOS 可考慮 du -hd 1。

du -h --max-depth=1 [目錄]
顯示磁碟與掛載資訊資源

列出區塊裝置、檔案系統及掛載點。

補充Linux 常用；容器內通常看不到主機所有裝置。

lsblk -f
搜尋掛載資訊資源

從目前已掛載的檔案系統中篩選。

補充用於確認磁碟或網路掛載點。

mount | grep [關鍵字]
查看系統運作時間資源

顯示開機時長與平均負載。

補充平均負載不能直接等同處理器百分比。

uptime
查看核心與平台系統

顯示作業系統核心與平台資訊。

補充有助於確認核心版本與硬體架構。

uname -a
查看主機身分系統

顯示主機名稱與系統資訊。

補充需要 systemd（系統服務管理程式）；不是每個容器都有。

hostnamectl
查看目前使用者權限

印出執行命令的帳號名稱。

補充與 id 的詳細識別資訊互補。

whoami
查看使用者與群組識別權限

顯示 UID（使用者識別碼）和所屬群組。

補充用於判斷權限相關問題。

id
依名稱尋找程序程序

列出符合關鍵字的程序識別碼與完整命令列。

補充某些系統可能不支援 -a 選項。

pgrep -af [關鍵字]
要求程序正常結束謹慎

發送 TERM（終止）訊號，讓程序有機會清理資源。

注意先用 ps 或 pgrep 確認 PID（程序識別碼）。

kill -TERM [PID]
檢查系統事件紀錄

查看近期系統日誌與相關提示。

補充僅適用使用 systemd 的系統。

journalctl -xe
查看最近一小時日誌紀錄

篩選指定時間範圍內的系統紀錄。

補充必要時加 -u [服務] 限縮來源。

journalctl --since "1 hour ago"
跨檔案搜尋文字搜尋

遞迴搜尋目錄、顯示行號且忽略大小寫。

補充大型目錄或二進位檔可能耗時；可排除不必要路徑。

grep -Rni "[關鍵字]" [目錄]
查看 inode 使用量資源

列出 inode（檔案索引節點）容量與使用情況。

補充磁碟還有空間卻不能新增檔案時可檢查。

df -i
使用標準欄位查看程序程序

顯示程序擁有者、識別碼與命令。

補充和 ps aux 的欄位略有不同。

ps -ef
03

網路與遠端

位址、路由、連通性、網域查詢與安全連線。

23 條
查看網路介面位址網路

查看網路介面及 IP（網際網路協定位址）設定。

補充這是 Linux 常見指令；macOS（蘋果電腦系統）可改用 ifconfig。

ip addr
測試基本網路可達性網路

透過網路控制訊息測試目標是否回應。

補充按 Ctrl+C 停止；無回應不一定代表服務無法使用，可能被防火牆阻擋。

ping [IP / 網域]
發出網頁請求網路

向指定網址發出請求並查看回傳內容。

補充例如 curl -I https://example.com 只查看回應標頭。

curl [網址]
查看連接埠與監聽程序連接埠

列出網路套接字、監聽中的 TCP／UDP（傳輸控制協定／使用者資料包協定）連接埠及程序。

補充部分程序資訊需管理權限才能完整查看；主要適用於 Linux。

ss -tulpn
登入遠端主機遠端

透過 SSH（安全殼層協定）連線到遠端系統。

補充把 user 換成帳號、host 換成主機名稱或位址；需要相應的登入憑證。

ssh user@host
查看路由表網路

顯示目前的封包路由與預設閘道。

補充Linux 常用；macOS 可用 netstat -rn。

ip route
查看網卡連線狀態網路

列出網路介面與連線旗標。

補充搭配 ip addr 可看到位址設定。

ip link
查看 DNS 解析設定DNS

檢視 systemd-resolved（名稱解析服務）的狀態。

補充未使用 systemd-resolved 的環境可能沒有此指令。

resolvectl status
查詢 DNS 紀錄DNS

查看網域的 DNS（網域名稱系統）解析結果。

補充可能需要先安裝 dnsutils 或 bind-utils。

dig [網域]
簡潔查詢 DNSDNS

只顯示常用解析結果。

補充不一定顯示所有 DNS 記錄或錯誤原因。

dig +short [網域]
查詢網域解析DNS

使用 DNS 伺服器解析網域。

補充在多數平台可用，但詳細診斷建議使用 dig。

nslookup [網域]
查看 HTTP 回應標頭HTTP

以 HEAD 方法取得回應標頭。

補充部分網站的 HEAD 回應與 GET 不一定相同。

curl -I [網址]
顯示請求與連線細節HTTP

輸出連線過程與 HTTP/TLS（加密連線）除錯資訊。

補充輸出可能包含敏感標頭，分享前應遮蔽。

curl -v [網址]
下載並保留檔案下載

跟隨重新導向並儲存回傳內容。

補充下載前確認網址可信，避免直接執行未知內容。

curl -L -o [檔名] [網址]
查看 TCP 監聽連接埠連接埠

顯示正在監聽的 TCP（傳輸控制協定）埠號與程序。

補充需要足夠權限才能看到部分程序。

ss -ltnp
測試 TCP 連接埠連接埠

嘗試建立連線，不傳送實際應用資料。

補充常用於排查防火牆與服務監聽；需安裝 netcat。

nc -vz [主機] [連接埠]
追蹤網路路徑網路

查看封包經過的網路節點。

補充部分路由器會忽略探測封包；可能需要安裝套件。

traceroute [網域]
指定埠號進行遠端連線遠端

透過 SSH（安全殼層協定）連線至非預設連接埠。

補充預設為 22，請確認主機實際設定。

ssh -p [連接埠] [使用者]@[主機]
建立 SSH 金鑰安全

產生 Ed25519（橢圓曲線）型態的公私鑰。

補充不要分享私鑰；建議設定密碼片語。

ssh-keygen -t ed25519
複製檔案到遠端遠端

使用 SSH 安全通道傳輸檔案。

補充路徑包含空白時需正確引用。

scp [本機檔案] [使用者]@[主機]:[目的地]
預覽同步檔案同步

顯示將同步的檔案而不真正改動資料。

補充來源結尾的 / 會影響複製目錄本身或其內容。

rsync -av --dry-run [來源]/ [目的地]/
查看區域網路鄰居表網路

列出 ARP（位址解析協定）／鄰居探索快取中的位址。

補充只代表本機已知的鄰居，並非網段掃描。

ip neigh
顯示本機網路位址網路

顯示目前主機的 IP（網際網路協定位址）清單。

補充通常適用 Linux，結果可能包含多個介面。

hostname -I
04

服務與排程

systemd（系統服務管理程式）、日誌與排程管理。

14 條
查看服務狀態服務

檢視服務是否啟動、狀態與最近的執行資訊。

補充例如 systemctl status nginx；此指令適用於使用 systemd 的 Linux。

systemctl status [服務]
重新啟動服務謹慎

停止並重新啟動指定服務。

注意可能短暫中斷連線或處理中的工作，先確認影響範圍。

systemctl restart [服務]
即時追蹤服務紀錄紀錄

查看指定服務新增的系統日誌內容。

補充按 Ctrl+C 結束；若要查看歷史內容可去掉 -f。

journalctl -u [服務] -f
列出執行中服務服務

顯示目前處於執行狀態的服務。

補充需在使用 systemd 的 Linux 主機執行。

systemctl list-units --type=service --state=running
判斷服務是否執行服務

用簡潔的結果查看服務狀態。

補充指令的結束狀態可用於自動化。

systemctl is-active [服務]
檢查開機啟動服務

確認指定服務是否設定為開機啟動。

補充不代表目前正在執行。

systemctl is-enabled [服務]
啟動服務謹慎

啟動已存在的服務單元。

注意可能啟用對外連線或產生工作負載。

systemctl start [服務]
停止服務謹慎

要求指定服務停止運作。

注意執行中的連線可能被中斷。

systemctl stop [服務]
設定開機啟動謹慎

讓服務依相應的安裝設定自動啟動。

注意不會立即啟動服務；需要啟動可另用 start。

systemctl enable [服務]
重新讀取服務設定服務

載入變更過的服務單元檔案。

補充不會自動重新啟動正在執行的服務。

systemctl daemon-reload
讀取最近服務紀錄紀錄

查看指定服務最後一百筆系統日誌。

補充適合留存和分享排錯結果，先遮蔽敏感資訊。

journalctl -u [服務] -n 100 --no-pager
列出使用者排程排程

顯示目前帳號的 cron（週期工作排程）設定。

補充某些環境使用 systemd timer 取代 cron。

crontab -l
編輯使用者排程謹慎

開啟目前使用者的 cron 排程設定。

注意存檔後可能立即改變執行排程，先備份。

crontab -e
列出定時器排程

檢視 systemd timer（系統定時器）的下次執行時間。

補充只適用於使用 systemd 的系統。

systemctl list-timers --all

Shell（命令列）工具

串接指令、環境變數、管線與檢索。

11 條
查詢指令位置環境

檢查命令是否存在及其解析結果。

補充比依賴 which 更適合寫入可攜式 Shell 腳本。

command -v [指令]
列出環境變數環境

查看目前程序可存取的環境設定。

補充輸出可能包含憑證或 Token（存取權杖），不應直接分享。

env
設定環境變數環境

將變數提供給後續啟動的子程序。

補充若值包含空白，應以引號包住。

export [名稱]=[值]
查看曾執行的命令環境

顯示 Shell（命令列殼層）的歷史記錄。

補充不同 Shell 的紀錄方式可能不同；可能包含敏感命令。

history
建立命令別名環境

為常用指令設定縮寫。

補充通常只對目前 Shell 會話有效。

alias [名稱]='[指令]'
成功才執行下一步流程

只有第一個指令成功退出才執行第二個。

補充常用於有依賴順序的工作流程。

[指令1] && [指令2]
將輸出傳給下一個指令流程

用管線串接兩個命令的標準輸出與輸入。

補充管線結束狀態通常由最後一個指令決定。

[指令1] | [指令2]
覆寫輸出檔謹慎

將標準輸出重新導向檔案。

注意會覆蓋既有檔案內容，執行前先確認。

[指令] > [檔名]
附加輸出到檔案流程

將標準輸出加到檔案末尾。

補充避免對錯誤位置持續追加大量資料。

[指令] >> [檔名]
統計連續重複內容文字

先排序，再統計重複行出現次數。

補充uniq 只會合併相鄰相同的行。

sort [檔名] | uniq -c
抽取指定欄位文字

以冒號作為分隔符號，取第一欄。

補充適合規則一致的純文字資料。

cut -d ':' -f 1 [檔名]

軟體安裝與更新

Ubuntu／Debian 的 APT（套件管理工具）及常見程式設定。

11 條
查看已安裝套件套件

列出系統中已安裝的軟體套件。

補充輸出可能很長，可使用 grep 篩選名稱。

apt list --installed
搜尋軟體套件套件

在套件索引中尋找符合名稱的程式。

補充套件名稱未必與執行檔名稱相同。

apt search [名稱]
查看軟體套件資料套件

顯示版本、相依項目與描述。

補充通常不會修改系統。

apt show [套件]
更新可用套件清單更新

向已設定的套件來源更新版本索引。

補充不會直接安裝新版軟體，需要網路與管理權限。

sudo apt update
檢查可升級套件更新

查看套件清單中可用的更新。

補充通常先執行 sudo apt update 再查看。

apt list --upgradable
升級已安裝套件謹慎

套用可行的軟體更新，可能涉及服務重新啟動。

注意正式系統先做備份及變更評估。

sudo apt upgrade
安裝指定軟體謹慎

從已設定的套件來源下載並安裝套件。

注意安裝可能啟動服務或修改相依套件。

sudo apt install [套件]
移除指定軟體謹慎

移除套件，通常保留部分設定檔。

注意可能影響相依程式或服務。

sudo apt remove [套件]
移除不再需要的相依套件謹慎

清除套件管理器判定不再被使用的套件。

注意先檢查即將移除的清單。

sudo apt autoremove
查看 Debian 套件安裝狀態套件

列出 dpkg（底層套件管理工具）記錄的套件。

補充適用 Debian／Ubuntu 系統。

dpkg -l
查詢檔案所屬套件套件

找出已安裝檔案由哪個套件提供。

補充僅能查詢 dpkg 有登錄的路徑。

dpkg -S [檔案路徑]
找不到指令

請調整搜尋條件。
